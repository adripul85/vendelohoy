## 2024-05-15 - Missing token validation in Vercel endpoints
**Vulnerability:** A critical authentication and authorization bypass vulnerability (IDOR) was found in `api-handlers/dispatch-courier.ts`. The endpoint checked for the presence of a Bearer token in the header but failed to actually verify the token signature using `adminAuth.verifyIdToken(token)`. Furthermore, it lacked an authorization check to ensure the caller was the rightful owner (seller) of the transaction being modified.
**Learning:** In Vercel serverless functions interacting with Firebase via `firebase-admin`, simply checking for a token's existence is a severe security gap. Token validation must be explicit, and IDOR vulnerabilities can exist even if a valid token is provided, if data ownership (caller UID vs. resource owner ID) is not verified.
**Prevention:** Always use `adminAuth.verifyIdToken(token)` to validate incoming requests in API handlers. After decoding the token, explicitly verify that `decodedToken.uid` has the necessary permissions to access or modify the requested resource (e.g., verifying they are the seller or an admin).
